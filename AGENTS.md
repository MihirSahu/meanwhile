## Server lifecycle

The user requires explicit permission before starting a server, except servers needed for a test. Stop every test server after its test finishes, including failures/cancellation. Never leave a dev or preview server running after a task. Prefer the managed Playwright webServer fixture with reuseExistingServer=false and verify shutdown afterward.
